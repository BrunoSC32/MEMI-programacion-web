# MEMI-programacion-web

Sitio web institucional del Centro MEMI (Centro de Mejoramiento de la Enseñanza de la Matemática e Informática) de la UMSS.

Este proyecto implementa un diseño moderno, responsivo y mobile first, utilizando HTML, CSS y JavaScript puro. El sitio contiene información sobre cursos, seminarios, servicios, publicaciones y actividades destacadas del Centro MEMI.

## Características principales

- Diseño responsivo y mobile first
- Carrusel de avisos e imágenes
- Secciones de cursos, publicaciones y eventos
- Información de contacto e integración con redes sociales
